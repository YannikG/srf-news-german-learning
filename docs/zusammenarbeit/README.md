# Zusammenarbeit (SSOT)

Kanonical für Tracker-Issues: Permalink zur jeweiligen Spec unter `docs/roadmap/phase-N/issues/*.md` im Issue-Body; die Markdown-Datei bleibt die kanonische Spec.

**GitHub:** Jedes Roadmap-Issue hat ein Label `phase-1` … `phase-7`. Bulk-Erstellung aus den Specs (Parser inkl. Abhängigkeiten): [`scripts/gh_roadmap_issues.py`](../../scripts/gh_roadmap_issues.py) — nicht erneut ausführen, wenn die Issues schon existieren (sonst Duplikate).
